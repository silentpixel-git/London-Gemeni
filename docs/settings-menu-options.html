Where the appearance & sound settings should live

Three ways to move the four header icons (dark mode, time-of-day colours, sound effects, ambient sound) into a proper player menu — and to fix the hidden conflict between them.

The real problem: there aren't two independent settings fighting each other. There are four themes — light, dark, evening, night — all competing for one slot (data-theme). "Time-of-day colours" simply hands the theme over to the in-game clock (evening/night), which is why it silently cancels dark mode. So the honest model is one choice — Light / Dark / Auto-by-the-hour — not two toggles. Sound is genuinely separate. All three options below group it that way.

Option 1 — Appearance modes

A settings panel with one three-way choice. Conflict becomes impossible.

Why it works: "Auto" is the old time-of-day toggle, reframed as a peer of Light & Dark. You can only pick one, so dark mode can never be silently overridden. Mirrors the Light/Dark/Auto pattern players already know from iOS & macOS.

Lightest touch: no new screen, smallest code change. Same Light/Dark/Auto fix as Option 1, just in a compact popover triggered by a single header icon — the other three icons disappear.

My recommendation

Option 1 if settings will grow (difficulty, text size, accessibility) — a real panel gives them a home and the labelled cards make the time-of-day idea self-explanatory. Option 3 if you want the smallest, fastest change that still kills the conflict. Option 2 only if you specifically want to keep "atmospheric" feeling like a separate effect layered on top — it's the most novel but asks the player to understand the override.

All three share the one essential fix: Light / Dark / Auto are mutually exclusive, so dark mode can never be silently swallowed by the time-of-day tint again. Sound effects and ambient sound stay as independent toggles, in their own section — as you asked.
