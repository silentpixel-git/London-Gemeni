About question 5 — yes, the menu can resize

Today both pages sit side by side inside a w-[200%] flex row, so the dropdown is always as tall as the taller page (Settings) — that's the blank strip you see under the short menu. The fix used in this mock: wrap the slider in an overflow-hidden viewport and, on open and on every page change, set the viewport's height to the active page's measured height with a CSS height transition. In React that's a small ref-based effect in Header.tsx; no restructuring needed. Variant B and C avoid the issue entirely since they only ever show one column of content.
