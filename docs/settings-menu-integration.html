"Settings" inside the profile menu

Three ways the four header icons collapse into a single Settings entry in the profile dropdown. Click each avatar to open the menu, then Settings. Defaults: Light mode, sound off. The page behind recolors live.

Heads-up — the guest case: the profile menu only appears when signed in. Signed-out players (who see the "Sign In" pill) would lose all theme/sound control. Cheapest fix: keep one gear icon in the header for the signed-out state that opens the same panel — or show a minimal menu under a lone gear when there's no profile. Flagging so we decide it deliberately rather than by accident.

Recommendation

Iteration B (slide sub-page) is the sweet spot: the dropdown never grows tall, Settings gets a clean home that can hold difficulty/text-size later, and it feels native (the same pattern as iOS settings). A is fine if Settings will always be just these three controls. C only earns its weight once Settings has a lot more in it.

Whichever we pick, the menu label is Settings, and the panel opens on Light · sound off by default. Theme is the single Light / Dark / Auto choice — so the old dark-vs-time-of-day conflict is gone.
