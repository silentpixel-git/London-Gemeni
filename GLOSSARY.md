# Glossary

**Authored fact**
A single piece of world knowledge written by the author, with who knows it and from which act it is visible.
_Avoid_: lore, knowledge blob

**Ledger**
The per-character record of which authored facts that character has said aloud and which facts the player has told them. It is the only source for what a character remembers.
_Avoid_: memory, NPC memory

**Improvised note**
A detail the narrator invented about an unauthored thing (a chimney, a passer-by) and which is then remembered against that thing so it stays consistent. Never a clue, never an authored fact.
_Avoid_: hallucination, flavor text

**Compound turn**
One player input containing several ordered requests ("look at the lamp, then tell me anything interesting"), resolved in sequence and narrated once.

**Idle pulse**
A small world advance triggered when the player has been silent for a while, which may surface an ambient event.
_Avoid_: real-time tick

**Gazetteer**
The authored list of real period places, people and events that every character can talk about by default.
_Avoid_: world lore, wiki

**Ignorance marker**
An explicit author note that a particular character does not know a particular thing. It is the only legitimate reason for a character to say they do not know.
